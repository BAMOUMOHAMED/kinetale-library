# VidMate 3D model library

Free 3D models used by the VidMate Studio plugin for Claude Code: **105 packs, 7,415 models**, all
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain: free for any use, including monetised
videos, no credit required).

The files are in this repository's [releases](https://github.com/BAMOUMOHAMED/vidmate-library/releases). The plugin
downloads them on first use; you don't need to download anything by hand.

| Maker | Packs | Where the originals are |
| --- | --- | --- |
| Kenney | 50 kits: food, furniture, nature, castles, pirates, cities, cars, space and more | [kenney.nl](https://kenney.nl/assets) |
| Quaternius | 51 packs, including the Fantasy Props, Medieval Village and Stylized Nature megakits | [quaternius.com](https://quaternius.com) |
| KayKit (Kay Lousberg) | Medieval Builder, Dungeon, Mini-Game Variety, Spooktober | [kaylousberg.itch.io](https://kaylousberg.itch.io) |

Each pack was repackaged with only its model, texture and licence files, plus a `SOURCE.txt` naming its maker and
original page. `library.json` in each release lists every pack and model with sha256 checksums.

Thank you to Kenney, Quaternius and Kay Lousberg for releasing their work into the public domain. If you like their
models, please support them on their own sites.
